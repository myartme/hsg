# Система уведомлений об обновлениях

## Обзор

Система автоматической проверки обновлений данных с сервера при запуске приложения. Изменения применяются автоматически, пользователь получает уведомление о том, что изменилось.

## Поток данных

```
App Start
    ↓
loadSets() (существующий)
    ↓
checkForUpdates()
    ↓
┌─────────────────────────────────────┐
│ 1. Загрузить role_sets с сервера   │
│ 2. Загрузить каждый сет с сервера  │
│ 3. Загрузить night_order с сервера │
│ 4. Загрузить queue_positions       │
│ 5. Загрузить bootlegger            │
│ 6. Сравнить с локальными данными   │
│ 7. Применить изменения             │
│ 8. Сохранить уведомление           │
└─────────────────────────────────────┘
    ↓
Есть изменения?
    ├─ Да → Показать модальное окно (информирование)
    │         ↓
    │       Кнопка "Понятно" → закрыть
    │
    └─ Нет → Продолжить работу
```

## Структура данных

### Уведомление

```javascript
{
  id: 'upd_1706234567890',        // уникальный ID
  timestamp: 1706234567890,       // когда пользователь получил
  title: 'Обновление библиотеки', // заголовок для колокольчика
  changes: [
    {
      type: 'role_image_changed',
      roleId: 'washerwoman',
      roleName: 'Washerwoman',
      setName: 'Trouble Brewing',
      oldValue: '/images/old.png',
      newValue: 'https://wiki.../new.png',
      message: 'У роли Washerwoman обновилась картинка'
    }
  ]
}
```

| `role_removed` | Роль удалена | "Из сета {setName} удалена роль: {roleName}" |
| `role_image_changed` | Изменилась картинка | "У роли {name} обновилась картинка" |
| `role_ability_changed` | Изменилась способность | "У роли {name} изменилась способность" |

| `role_reminders_changed` | Изменились напоминания | "У роли {name} изменились напоминания" |

## Логика применения изменений

### Числовые порядки (firstNight, otherNight, scriptCharacterPriority)

При изменении значения:
1. Найти роль в локальном списке
2. Обновить значение
3. Пересортировать весь список по возрастанию

### Удаление роли

1. Создать сет `deleted_roles` если не существует:
   - id: `deleted_roles`
   - name: `Удалённые роли`
   - logo: `trash_set_icon.png`
   - isOfficial: false
2. Переместить роль в этот сет
3. Удалить из оригинального сета

### Новый сет на сервере

1. Автоматически скачать сет
2. Добавить в библиотеку как дефолтный
3. Добавить в список для восстановления в настройках

## UI компоненты

### NotificationBell (в AppMenu)

- Иконка колокольчика справа от "Опции"
- Бейдж с количеством непрочитанных (если > 0)
- При клике открывается NotificationDropdown

### NotificationDropdown

- Список уведомлений (последние 20)
- Каждый элемент: краткий заголовок + дата/время
- При клике на элемент — открывается UpdatesModal с деталями
- Внизу кнопка "Очистить"

### UpdatesModal

- Заголовок: "Обновление библиотеки"
- Список изменений (message из каждого change)
- Кнопка "Понятно" внизу

## Хранение данных

Файл: `notifications.json` в userData

```javascript
{
  notifications: [...], // массив уведомлений, макс 20
  lastCheck: 1706234567890 // timestamp последней проверки
}
```

## Интернационализация

Добавить ключи в локали:
- `updates.title` — "Обновление библиотеки"
- `updates.button_ok` — "Понятно"
- `updates.clear` — "Очистить"
- `updates.no_notifications` — "Нет уведомлений"
- Все типы сообщений об изменениях
